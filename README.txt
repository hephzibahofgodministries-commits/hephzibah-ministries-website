HEPHZIBAH OF GOD MINISTRIES WEBSITE
==================================

This is a static HTML/CSS/JavaScript website prepared for GitHub Pages.

FILES
- index.html: homepage
- about.html: ministry information
- sermons.html: sermons and Bible teachings
- radio.html: Hephzibah Waves page (stream URL still needs to be added)
- programmes.html: programmes and events
- resources.html: discipleship and evangelism resources
- contact.html: contact information placeholders
- assets/style.css: website design and mobile layout
- assets/site.js: mobile navigation and automatic copyright year

HOW TO PUBLISH
1. Upload all files and the assets folder to the ROOT of your GitHub repository.
2. Keep index.html at the repository root.
3. In the repository, open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for deployment and open the Pages URL.

IMPORTANT BEFORE PUBLIC LAUNCH
- Replace bracketed placeholders on About and Contact pages with approved ministry details.
- Confirm the Annual Interdenominational Retreat 2026 details and venue.
- Supply the verified direct audio stream URL before adding a live radio player.
- Add only approved public contact details and ministry media.
- This static site does not yet include a working prayer-request backend, member database, payment processing or user login.
