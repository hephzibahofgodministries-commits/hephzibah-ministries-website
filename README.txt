HEPHZIBAH OF GOD MINISTRIES WEBSITE — VERSION 2

Includes Home, About Us, Leadership, Sermons, Hephzibah Waves, Programmes, Resources, Contact, plus assets/style.css and assets/site.js.

INSTALL:
1. Download and extract this ZIP.
2. Open your existing GitHub repository.
3. Upload all HTML files to the repository root, replacing files with the same names.
4. Upload assets/style.css and assets/site.js inside the assets folder.
5. Commit changes to the branch GitHub Pages uses (usually main).
6. Keep index.html at the publishing root. Under Settings > Pages, verify branch and /(root) if branch publishing is used.
7. Wait a few minutes and refresh the website.

The website is public. Contact information on contact.html is displayed publicly. Hephzibah Waves needs the direct audio-stream URL before a live player can be activated. Forms, logins, databases and payments require a suitable external service or backend.
