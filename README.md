## Integrate into the existing GitHub Pages website
1. Unzip this package on your computer.
2. Open the existing repository: `hephzibah-ministries-website`.
3. Upload `anniversary.html` to the same published root folder as the site's existing `index.html`.
4. Upload `assets/anniversary.css` and `assets/anniversary.js` into the repository's existing `assets` folder. Do not overwrite unrelated files.
5. Open the existing `index.html` and add the line from `index-link-snippet.html` inside its navigation menu.
6. Commit the changes to the branch/folder used by GitHub Pages.
7. Test both the homepage and the anniversary page:
   `https://hephzibahofgodministrie-commits.github.io/hephzibah-ministries-website/anniversary.html`
